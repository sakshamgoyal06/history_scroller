# Curiosity Feed

A calm, mobile-first learning PWA: a vertical "For You" feed of short story cards, curated
Learning Zones, and AI-built learning paths for any topic you type in.

Stack: React 19 + Vite 8 (PWA via `vite-plugin-pwa`), two Vercel serverless functions that
call the OpenAI Responses API, Zod for every API contract. All user data lives in
`localStorage` for now: there are no accounts and no database yet.

> Status: **v0.7, pre-production.** Product direction, MVP scope and GTM live in
> [`docs/PRD.md`](docs/PRD.md). The technical assessment, known issues and engineering roadmap live in
> [`docs/ENGINEERING_REVIEW.md`](docs/ENGINEERING_REVIEW.md).

## Features

| Area | What it does | Where |
|------|--------------|-------|
| **For You reel** | Full-screen slide/video posts, ranked on-device from likes, saves, "not interested" and domain preferences. Session summary after 8 posts. | `src/feed/` |
| **Explore** | The 46-card catalog with domain chips, topic and decade filters, Today's Edition and Story Mode. | `src/feed/ExplorePanel.jsx`, `src/dailyEdition.js`, `src/flagshipStories.js` |
| **Learning Zones** | Curated multi-step paths over catalog cards, with focus mode and "drip into feed". | `src/zones/` |
| **Learn a Topic** | User topic → AI plans a path (or asks to narrow it, or proposes multiple tracks) → each lesson is researched with web search and written on demand, with cited sources. | `api/`, `lib/`, `src/LearnTopicPanel.jsx`, `src/learningPathStorage.js` |
| **Library** | Saved cards, liked posts, recently viewed and your paths. | `src/library/` |

Domains: History · Economics · Geography · Civics · Technology · Current Affairs · Science · General Knowledge.

## Project layout

```
api/                      Vercel functions (one file = one endpoint)
  plan-learning-path.js     POST: topic → plan (single path / needs narrowing / multi-track)
  generate-lesson.js        POST: planned lesson → web research → structured lesson
lib/                      Server-only code shared by the endpoints
  learningPathSchemas.js    Zod contracts (request, model output, response)
  openaiPlanner.js          Planner prompt + structured output call
  openaiLesson.js           Research (web_search) + lesson writing calls
  normalizePlanShape.js     Repairs common model shape mistakes
  planIds.js                Replaces model IDs with stable, URL-safe IDs
  serverUtils.js            Body parsing, throttling, timeouts, safe errors
src/
  App.jsx                   App shell: state, navigation, story detail
  catalog.js                Built-in cards, normalized once (data in src/data/ + *Cards.js)
  routing.js                Hash routes + History API state (pure parseHash)
  feed/ zones/ library/     Feature modules
  learningPath*.js          Client API wrapper + localStorage persistence for paths
public/stories/           Card artwork (generated by scripts/generate-story-art.mjs)
public/content/           Remote feed index (fetched network-first; currently empty)
scripts/dev-api-server.mjs Local HTTP server that runs the api/ handlers
```

## Getting started

Requires Node 22.9+ (`.nvmrc`).

```bash
npm install
cp .env.example .env      # set OPENAI_API_KEY and OPENAI_MODEL to use live AI
npm run dev:api           # terminal 1: API on http://127.0.0.1:3001 (loads .env)
npm run dev               # terminal 2: app on http://localhost:5173 (proxies /api)
```

You don't need an API key to work on the UI. Without one, Learn a Topic shows a
"not configured" state with a **demo path** fallback, and `VITE_LEARN_FORCE_MOCK=true` always
uses the demo generator.

### Environment variables

| Name | Where | Purpose |
|------|-------|---------|
| `OPENAI_API_KEY` | server | Required for `/api/*`. |
| `OPENAI_MODEL` | server | Model ID that supports the Responses API, JSON-schema output and `web_search`. |
| `LEARN_API_PORT` | dev server | Port for `npm run dev:api` (default 3001). |
| `VITE_LEARN_FORCE_MOCK` | client (build time) | `true` forces the offline demo generator. |

## Deployment

Built for Vercel: `api/*.js` become functions (`maxDuration: 300`, see `vercel.json`) and every
other path rewrites to `index.html`. Set `OPENAI_API_KEY` and `OPENAI_MODEL` in the project's
environment variables. **Before you expose this publicly, read the P0 items in the engineering
review.** The AI endpoints have no authentication or spend cap.

## Testing the PWA

The manifest, service worker and offline shell are only built in production mode:

```bash
npm run build && npm run preview
```

Inspect them in DevTools → Application. Quick manual smoke test: For You ↔ Explore, filter by domain,
open a story and use **Continue learning**, save a card, open Zones / Library, reload to confirm
persistence, and generate a demo path in Learn.

## Data & storage

All state is per browser, in `localStorage`, under keys prefixed `curiosity-feed-*` (plus the legacy
`history-feed-saved` / `history-feed-known`). Clearing site data resets the app. Learning paths are
versioned (`PATH_SCHEMA_VERSION`). Bumping it without a migration currently discards stored paths.
